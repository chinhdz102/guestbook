# Paradise Nursery — Shopping Cart Application

Final React + Redux Toolkit project for the Paradise Nursery online houseplant shop.

## Assignment features
- Landing page with **Paradise Nursery** name, background image, **Get Started**, and About Us.
- **18 unique houseplants across three categories (6 per category)**, each with photo-style SVG thumbnail, name, description, and price.
- **Add to Cart** button disabled while that product is in the cart.
- Shared responsive navbar, Home / Plants / Cart links, and dynamically updating item count.
- Shopping cart: image, name, unit price, line total, quantity +/−, remove, order total, continue shopping, and Checkout **Coming Soon**.
- Redux Toolkit cart state with localStorage persistence.

## Quick start

Requires Node.js 20.19 or newer.

    npm install
    npm run dev

To build:

    npm run build
